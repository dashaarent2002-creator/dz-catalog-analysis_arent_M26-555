# Анализ каталога фильмов

Скрипт `catalog_analysis.py` считает статистику по каталогу фильмов и печатает
консольный отчет. Без pandas и других библиотек — только чистый Python и модуль `math`.

## Запуск

```bash
uv sync
uv run catalog_analysis.py
```

## Проверка стиля

```bash
uv run ruff check .
```
